# 🇹🇩 TchadSkills v2.0 - Plateforme d'Apprentissage Professionnelle

Bienvenue sur la version complète et améliorée de **TchadSkills**, la plateforme dédiée au développement des compétences numériques au Tchad.

## 🌟 Nouvelles Fonctionnalités (Upgrade Total)
- **Interface Moderne (UI/UX)** : Design épuré, responsive (mobile-friendly) et animations fluides.
- **Système de Cours Avancé** : Organisation par Modules et Leçons.
- **Lecteur Interactif** : Une interface dédiée pour l'apprentissage avec suivi de progression.
- **Tableau de Bord Étudiant** : Suivez vos cours et votre avancement en temps réel.
- **Administration Puissante** : Gérez les instructeurs, les cours et les inscriptions.

## 🛠️ Installation Rapide
Pour lancer le site sur votre ordinateur (Ubuntu/WSL) :

1. **Préparer l'environnement** :
   ```bash
   chmod +x setup.sh
   ./setup.sh
   ```

2. **Lancer le serveur** :
   ```bash
   source venv/bin/activate
   python3 manage.py runserver
   ```

3. **Accéder au site** :
   👉 [http://127.0.0.1:8000](http://127.0.0.1:8000)

## 🔐 Accès Démo (Mode Administrateur)
Pour gérer la plateforme :
- **URL** : [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin)
- **Identifiant** : `admin`
- **Mot de passe** : `admin123`

## 🚀 Déploiement Cloud
Le projet est prêt pour un déploiement sur **Render** ou **Railway** grâce au `Dockerfile` et au fichier `render.yaml` inclus.
